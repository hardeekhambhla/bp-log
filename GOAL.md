# BP Log

Minimal iOS-native-looking blood pressure logger for family. Profiles (Mom, Dadima, Dada, Dad
seeded on first load; more can be added/renamed/deleted). Each profile has day-wise reading
history (sys/dia/pulse/note/time), latest card, trend chart. Deployed on Cloudflare Pages.

Rules: keep it minimal; palette = iOS system neutrals + blue accent, green/orange/red only for
BP-category dots. No build step, no dependencies.
